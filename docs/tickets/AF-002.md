## Plan and risk assessment

Own all eight versioned contracts in `core/schemas.py`. Use strict Pydantic v2
validation, reject extra fields, require explicit version `1`, reject unknown
versions (no implicit migration yet), export JSON Schema, and round-trip real JSON.
Use typed action arguments and known action/check enums; never accept host shell
commands. Require immutable evidence digests and consistent citations, separate
quality/safety/outcome fields, and UNKNOWN with no score or confidence.

Regression cases: unsupported/missing versions, unknown actions/fields, incomplete
risk attributes, mismatched action arguments, path traversal, duplicate scenario
declarations, malformed timestamps, fabricated scores, invalid counts, mismatched
outcomes and cross-run report references. Wire validation is not authorization,
filesystem containment, evidence hash verification, or execution isolation.
