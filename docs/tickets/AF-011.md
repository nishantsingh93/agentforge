## Limitations and next ticket

Citation validity does not establish semantic truth. Inputs must come from trusted
sanitized collector output; hashes cannot establish authenticity if a caller forges
an entire run. Python providers are trusted installed code, not OS-confined plugins.
No vendor transport, live model quality/calibration, minimum Python 3.12 or other
platform verification is claimed. Model version is caller-pinned; providers own
network timeouts. AF-014 owns persistence and end-to-end orchestration.
